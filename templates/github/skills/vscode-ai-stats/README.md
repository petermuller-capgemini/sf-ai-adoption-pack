# VSCode AI Statistics Skill

**Status**: ✅ Fully functional (cross-platform)

## Overview

Retrieves detailed AI usage statistics from VSCode's internal state databases, including GitHub Copilot metrics.

## Features

- **Cross-platform support**: Works on macOS, Windows, and Linux
- **Comprehensive metrics**: Typed characters, AI characters, accepted suggestions, chat edits
- **Account information**: GitHub Copilot account, subscription type, extension versions
- **Model details**: Active AI model configuration (Claude Sonnet, GPT-4, etc.)
- **Zero dependencies**: Uses only Python standard library (sqlite3, json, pathlib)

## Usage

```bash
python3 .github/skills/vscode-ai-stats/scripts/fetch_ai_stats.py
```

## Output Format

```json
{
  "platform": "darwin",
  "vscode_dir": "/Users/username/Library/Application Support/Code/User",
  "stats_found": true,
  "account": "username_ABC1",
  "subscription": "copilot_standalone_seat_quota",
  "copilot_chat_version": "0.36.2",
  "copilot_completions_version": "1.378.1799",
  "aiStats": {
    "sessions": [
      {
        "startTime": 1770060765651,
        "typedCharacters": 0,
        "aiCharacters": 10960,
        "acceptedInlineSuggestions": 0,
        "chatEditCount": 3
      }
    ]
  },
  "source_db": "/path/to/state.vscdb"
}
```

## Metrics Explained

- **typedCharacters**: Characters manually typed by the user
- **aiCharacters**: Characters generated by AI (Copilot, Chat)
- **acceptedInlineSuggestions**: Number of inline Copilot suggestions accepted
- **chatEditCount**: Number of code edits initiated via chat
- **startTime**: Unix timestamp (milliseconds) when session started

## Platform-Specific Paths

- **macOS**: `~/Library/Application Support/Code/User/`
- **Windows**: `%APPDATA%/Code/User/`
- **Linux**: `~/.config/Code/User/`

## Requirements

- Python 3.6+
- VSCode with `editor.aiStats.enabled` setting enabled
- Active usage of AI features (Copilot, Chat)

## When to Use

User asks about:

- AI usage statistics
- Copilot acceptance rates
- AI productivity metrics
- "How much AI have I used?"
- Editor.aiStats data
