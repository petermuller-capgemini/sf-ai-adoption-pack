# VSCode AI Statistics

Retrieve detailed AI usage statistics from VSCode's internal state databases, including GitHub Copilot metrics like accepted inline suggestions, AI-generated characters, typed characters, and chat edit counts.

## When to Use This Skill

- User asks about AI usage statistics or productivity metrics
- User wants to see Copilot acceptance rates or completion data
- User mentions "editor.aiStats" or AI coding statistics
- User wants to track AI-assisted coding productivity
- User asks "how much AI have I used?" or similar queries

## What This Skill Provides

**Metrics Retrieved:**
- **Typed Characters**: Characters manually typed by the user
- **AI Characters**: Characters generated by AI
- **Accepted Inline Suggestions**: Number of Copilot suggestions accepted
- **Chat Edit Count**: Number of code edits initiated via chat
- **Session Start Time**: When the current session began
- **GitHub Copilot Account**: Active Copilot account name
- **Extension Versions**: Copilot Chat and Completions versions
- **Active Model**: Currently selected AI model (e.g., Claude Sonnet 4.5, GPT-4.1)

## Usage Workflow

### 1. Execute the Statistics Script

Run the bundled Python script that automatically detects the OS and searches VSCode state databases:

```bash
python3 .github/skills/vscode-ai-stats/scripts/fetch_ai_stats.py
```

**Cross-Platform Support:**
- **macOS**: Searches `~/Library/Application Support/Code/User/`
- **Windows**: Searches `%APPDATA%/Code/User/`
- **Linux**: Searches `~/.config/Code/User/`

### 2. Parse the Output

The script outputs structured JSON with AI statistics:

## Script Details

### fetch_ai_stats.py

**Purpose**: Cross-platform Python script that searches VSCode state databases for AI usage data

**Key Features:**
- Detects OS automatically (Windows/macOS/Linux)
- Searches all workspace state databases
- Extracts `aiStats` entries from SQLite databases
- Returns structured JSON output
- Handles missing databases gracefully

**Dependencies:**
- Python 3.6+ (standard library only)
- `sqlite3` module (included with Python)
- `json` module (included with Python)
- `pathlib` module (included with Python)

**Error Handling:**
- Returns empty result if no VSCode installation found
- Skips corrupted databases
- Handles missing `aiStats` entries gracefully
- Reports database read errors without failing

## Important Notes

1. **Session-based Data**: The `editor.aiStats.enabled` setting tracks data per session. If it was recently enabled, statistics may be limited.

2. **Workspace Isolation**: Each workspace maintains separate statistics in its own state database.

3. **Global vs Workspace**: Some data is stored globally (account info, extensions) while usage metrics are workspace-specific.

4. **Privacy**: The script only reads metadata and statistics—it does NOT access code, prompts, or sensitive data.

5. **Real-time Updates**: Statistics update as the user works but may have a slight delay before appearing in the database.

## Troubleshooting

**No statistics found:**
- Verify `editor.aiStats.enabled` is set to `true` in VSCode settings
- Ensure the user has used AI features (Copilot, Chat) in the current session
- Check that VSCode version supports aiStats (requires recent versions)

**Script fails on Windows:**
- Ensure Python 3 is installed and in PATH
- Use `python` instead of `python3` on Windows
- Check that `%APPDATA%` environment variable is set

**Database locked error:**
- Close VSCode before running the script
- Or run the script while VSCode is open but idle (not actively saving)
